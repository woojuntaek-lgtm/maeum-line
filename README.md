# 마음 한 줄

감정 하나 누르고 한 줄 쓰는 **마음 일기**입니다. 이동 중에도 10초면 기록할 수 있게 만들었습니다. 파일 하나(`index.html`)로 동작하고 서버·로그인·광고가 없으며, 기록은 **내 폰 브라우저에만** 저장됩니다.

> **바로 사용하기: https://woojuntaek-lgtm.github.io/maeum-line/**

## 기능
- **오늘**: 기분 5단계 → 감정(20가지)·관련된 일(12가지) 고르기 → 날마다 바뀌는 질문에 한 줄. 하루에 여러 번 기록 가능
- **오늘의 자아상태**: 교류분석의 다섯 자아상태(CP·NP·A·FC·AC)를 0~3으로 10초 자기점검, 막대그래프와 한마디
- **달력**: 날마다 기분 이모지, 날짜를 누르면 그날 기록
- **흐름**: 7·30·90일 기분 그래프, 자주 느낀 감정, 기분을 올려 준 일, 자아상태 평균, 돌아보기
- **설정**: 4자리 가벼운 잠금, 백업·불러오기, CSV 내보내기
- 힘든 기분이 며칠 이어지면 상담전화(109, 1577-0199)를 조용히 안내

## 면책
스스로 마음을 돌아보기 위한 기록 도구입니다. 자아상태 체크는 표준화된 심리검사가 아닌 간이 자기점검이며 진단·상담·치료를 대신하지 않습니다.
